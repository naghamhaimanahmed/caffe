# Taste & Fun — Operations & Cost Control (UI Demo)

نسخة عرض تفاعلية لنظام التشغيل والتحكم بالتكاليف لمطاعم **تيست آند فن** (فرعا القصر الملكي ولؤلؤة بحري).
Next.js (App Router) + React + TypeScript + Tailwind CSS v4. واجهة عربية بالكامل باتجاه RTL. لا يوجد backend: كل البيانات وهمية.

## التشغيل

```bash
cd taste-fun
npm install
npm run dev     # http://localhost:3000
npm run build   # production build + type check
```

## تسجيل الدخول والصلاحيات (RBAC)

- `/` شاشة الدخول: زر "الدخول كـ المالك".
- أدوار مدير المطعم والمحاسب والشيف ومسؤول المشتريات ستُضاف لاحقًا في نظام كل مطعم، والذي سيُربط بعد ذلك بلوحة المالك.
- الدور النشط محفوظ في `AuthProvider` (React Context) في `lib/auth.tsx`، ويُحفظ في `sessionStorage` حتى لا تُفقد الجلسة عند تحديث الصفحة.
- كل صفحة ملفوفة بـ `<RoleGuard allow="…">`. أي دخول لصفحة لا يملك المستخدم صلاحيتها يُعاد توجيهه إلى `/`.
- زر "تسجيل الخروج" موجود في كل صفحة.

| المسار | الدور | التخطيط | المحتوى |
|---|---|---|---|
| `/owner` | المالك | سطح المكتب، قائمة جانبية (وشريط تبويبات على الموبايل) | لوحة المالك، بالتفصيل تحت |

### صفحات لوحة المالك

| الصفحة | المحتوى |
|---|---|
| نظرة عامة | شريط التنبيهات المهمة، مبيعات اليوم مقارنة بأمس، الطلبات ومتوسط الفاتورة، تكلفة الأغذية، الاعتمادات المعلّقة، كارت لكل مطعم، رسم مبيعات 14 يوم، والطلبات المباشرة من الكاشير (طلب جديد كل بضع ثوانٍ) |
| التقارير | اليوم / الأسبوع / الشهر / السنة، الأرباح والخسائر لكل مطعم وللمجموعة، مبيعات 12 شهر مقارنة بالسنة الماضية، المبيعات حسب القناة وطريقة الدفع، أوقات الذروة، الأصناف الأكثر والأقل مبيعًا، تصدير Excel/PDF (تجريبي) |
| التقفيل اليومي | لكل مطعم: أرقام الكاشير تلقائيًا أو إدخال يدوي، المصروفات النقدية، النقدية المعدودة والمتوقعة والفرق، إرسال / اعتماد / رفض، وحالة تقفيل أمس |
| العهدة اليومية | رصيد وتمويل العهدة والمتبقي، المصروفات حسب البند، تصنيف كل فاتورة، والاعتماد يتفعّل بعد تصنيف كل المصروفات |
| الاعتمادات | مشتريات ومصروفات وخصومات وساعات إضافية فوق حد المالك، اعتماد أو رفض |
| أسعار الموردين | آخر سعر مقابل متوسط 3 شهور، التكلفة الإضافية، أفضل سعر، فرصة الشراء المجمع، طلب عروض أسعار |
| المصروفات | إضافة مصروف مع صورة إيصال (أكثر من 500 د.إ يذهب للاعتمادات)، فواتير موردين مستحقة، مصروفات متكررة |
| المخزون | الرصيد مقابل الحد الأدنى في المستودع والمطعمين، تحويل من المستودع، إنشاء طلبات للأصناف المنخفضة |
| تكلفة المنيو | تكلفة وهامش كل صنف، مكوناته، والسعر المقترح لتكلفة 30% |
| الموردين والطلبات | طلبات الشراء (مسودة / مُرسل / مستلم) والاستلام يحدّث المخزون، وأداء الموردين |
| المطابخ المركزية | توصيلات اليوم للمطاعم والعملاء الخارجيين، والفواتير غير المدفوعة |
| التنبيهات | كل تنبيه يفتح الصفحة المعنية، والعدد يظهر على الجرس |
| المرحلة 2 | معاينات: الموظفين والشيفتات، الجرد والهدر، الأهداف الشهرية |

وفي الشريط العلوي: **الملخص اليومي** (معاينة رسالة واتساب الليلية) و**تخصيص الأسماء** (اسم المجموعة وشركة الأغذية والمطعمين يتغير في كل النظام).

## البنية

```
app/                 layout (RTL + AuthProvider) والصفحات لكل دور
components/          DesktopShell, RoleGuard, SalesChart, ui (Card, Button, Field…)
components/owner/    صفحات لوحة المالك
lib/auth.tsx         سياق المصادقة والأدوار
lib/owner-store.tsx  حالة لوحة المالك المشتركة بين الصفحات (الاعتمادات، المخزون، العهدة، الطلبات المباشرة…)
lib/finance.ts       حساب الأرباح والخسائر ومبيعات 12 شهر
lib/mock-data.ts     كل البيانات الوهمية
lib/format.ts        تنسيق الأرقام والعملة (د.إ)
```
