# Taste & Fun — Operations & Cost Control (UI Demo)

نسخة عرض تفاعلية لنظام التشغيل والتحكم بالتكاليف لمطاعم **تيست آند فن** (فرعا القصر الملكي ولؤلؤة بحري).
Next.js (App Router) + React + TypeScript + Tailwind CSS v4. واجهة عربية بالكامل باتجاه RTL. لا يوجد backend: كل البيانات وهمية.

## التشغيل

```bash
cd taste-fun
npm install
npm run dev     # http://localhost:3000
npm run build   # production build + type check
```

## تسجيل الدخول والصلاحيات (RBAC)

- `/` شاشة الدخول: 5 أزرار "الدخول كـ…" (المالك، المحاسب، مدير مطعم، الشيف، مسؤول المشتريات).
- الدور النشط محفوظ في `AuthProvider` (React Context) في `lib/auth.tsx`، ويُحفظ في `sessionStorage` حتى لا تُفقد الجلسة عند تحديث الصفحة.
- كل صفحة ملفوفة بـ `<RoleGuard allow="…">`. أي دخول لصفحة لا يملك المستخدم صلاحيتها يُعاد توجيهه إلى `/`.
- زر "تسجيل الخروج" موجود في كل صفحة.

| المسار | الدور | التخطيط | المحتوى |
|---|---|---|---|
| `/owner` | المالك | سطح المكتب، قائمة جانبية | مؤشرات (مبيعات اليوم، متوسط الفاتورة، تكلفة الطعام %، الموافقات)، مقارنة إغلاق الفرعين، رسم مبيعات 14 يوم (مع عرض جدول)، اعتماد/رفض الموافقات |
| `/accountant` | المحاسب | سطح المكتب | قائمة مراجعة الإغلاقات والعهد مع اختيار الحساب المحاسبي ثم اعتماد/إرجاع، تنبيهات ارتفاع أسعار الموردين مع حد تنبيه |
| `/manager` | مدير مطعم | جوال، تبويبات سفلية | الإغلاق اليومي (النقد المعدود/المتوقع وحساب الفرق تلقائيًا: مطابق/عجز/زيادة، عدّ الفئات)، العهدة (رقم الفاتورة، المبلغ، التصنيف، الرصيد المتبقي) |
| `/chef` | الشيف | جوال/تابلت | سجل الهدر (الصنف، الكمية، السبب: منتهي/محروق/وجبة موظفين، التكلفة التقديرية)، الوصفات القياسية للقراءة فقط (العائد، الحصة، الكميات للدفعة وللحصة) |
| `/purchaser` | مسؤول المشتريات | تابلت/جوال | أوامر الشراء (مسودة/مُرسل/مُستلم)، شاشة الاستلام (الكمية المستلمة وسعر الفاتورة مقابل آخر سعر)، سجل آخر الأسعار يتحدث بعد الاستلام |

## البنية

```

components/          DesktopShell, MobileShell, RoleGuard, SalesChart, ui (Card, Button, Field…)

lib/mock-data.ts     كل البيانات الوهمية
lib/format.ts        تنسيق الأرقام والعملة (د.إ)
```
